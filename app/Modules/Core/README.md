# Core

**Qué va aquí:** Project, User, Employee, ProjectMember, Module/ProjectModule (entitlements), ProjectSetting, AppSetting, el middleware de tenant y todo lo que los demás módulos dan por existente.

**Qué NO va aquí:** Ninguna entidad de negocio (productos, pedidos, clientes). Core no sabe qué vende el negocio.

**Orden en la mudanza:** No se mueve: se queda donde está y el resto depende de él.

**Estado:** vacío. El código sigue en su sitio actual hasta que le toque, según `docs/architecture/BIXO_MODULARIZACION_PLAN.md`.
