# Control

**Qué va aquí:** BIXO Control (superadmin): AccessEvent, licencias/sesiones, DemoRequest, logs globales, plantillas de proyecto.

**Qué NO va aquí:** Crear productos, clientes, empleados ni turnos de un tenant: el soporte entra por impersonación auditada, nunca escribiendo directo.

**Orden en la mudanza:** 2.º — aislado del resto.

**Estado:** vacío. El código sigue en su sitio actual hasta que le toque, según `docs/architecture/BIXO_MODULARIZACION_PLAN.md`.
